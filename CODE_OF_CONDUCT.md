# Кодекс поведения сообщества A650

Кодекс распространяется на всех участников проекта, включая сопровождающих. Он действует в задачах, запросах на слияние, комментариях и других обсуждениях проекта.

## Правила общения

- Уважайте участников с любым опытом. Если в сообщении об ошибке мало данных, объясните, какие сведения помогут разобраться.
- Обсуждайте конкретное техническое решение. При разногласиях по карте регистров укажите модель привода, версию прошивки, страницу руководства или результат измерения.
- Личные выпады, унижение, дискриминационные высказывания, домогательства, угрозы и травля недопустимы.
- Получите согласие человека, прежде чем публиковать его личные данные или частную переписку. Перед отправкой журналов и снимков экрана удалите из них чужие контактные данные.

## Как сообщить о нарушении

Откройте меню **…** рядом с публикацией и выберите **Report content**. Если доступен пункт **Report to repository admins**, через него можно обратиться к сопровождающим проекта. Чтобы сообщить GitHub о нарушении правил платформы, в том числе если жалоба касается сопровождающего, используйте [форму GitHub Support](https://support.github.com/contact/report-abuse).

Приложите ссылку на публикацию и кратко опишите, что произошло. Частные сведения передавайте только в обращении. [Инструкция GitHub по отправке жалобы](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

## Как рассматриваются обращения

Сопровождающие рассматривают контекст и учитывают тяжесть и повторяемость нарушения. Они могут попросить исправить комментарий, скрыть его, вынести предупреждение или ограничить участие в репозитории. Сведения из обращения передаются только тем, кто участвует в его рассмотрении. Давление на человека, добросовестно сообщившего о нарушении, также нарушает кодекс.
