# ONI A650 · промежуточная сборка 0.2.0.dev2

Windows x64. Распакуйте весь архив в доступную для записи папку.
Запустите `start-preview.cmd`; установка Python не нужна.
Откроется каталог с фильтром «Можно изменить офлайн» и подключится симулятор.
Версия показана в заголовке окна, точный коммит — в `BUILD-INFO.json`.
ПЧ и USB–RS-485 для этого сценария не требуются.

Управление проектом, выбор модели и фильтры перенесены в левую панель.
Нажмите «Скрыть панель», чтобы расширить таблицу; кнопка «☰» вернёт панель.
Рядом с поиском показано число параметров с учётом текущих фильтров.

## Оценка интерфейса за несколько минут

1. Нажмите «Открыть проект…» и выберите `examples/demo.a650.json`.
   Это демонстрационные значения, не заводские настройки и не рекомендации
   для двигателя. Примеры относятся к выбранной модели A650.
2. Найдите `F15.01`. Дважды нажмите ячейку «Проект»: откроется список
   именованных вариантов чётности. Выберите вариант, нажмите Enter.
   Параметры соединения от этого не меняются.
3. Найдите `F13.01`. Введите `35,5` или `35.5` в колонке «Проект».
   Проверьте «Отменить» / «Повторить» и сохранение проекта под новым именем.
4. Очистите поиск. Нажмите «Сравнить с проектом…» и выберите
   `examples/comparison.a650.json`. Включите «Только отличия».
   Выделите строки с Ctrl/Shift, нажмите «Взять выбранные из образца».
   Отмените перенос одним действием. Отсутствие значения отличается от нуля.
5. Снимите «Только отличия» и закройте сравнение. Нажмите «Считать из симулятора».
   Появятся демонстрационные показания enum, время и отличия от проекта.
   При отключении симулятора показания помечаются устаревшими.
6. Нажмите «Импорт ODS…», откройте `examples/synthetic-oni-profile.ods`.
   Это созданный нами пример по анализу EXE, не экспорт производителя.
   Проверьте Set/Read/Check, значения проекта и причины блокировки.
   Отметьте enum и перенесите в проект либо закройте окно без переноса.
   Числа без подтверждённого масштаба заблокированы, пароли скрыты.
7. Для полного каталога снимите «Можно изменить офлайн». Для настроек порта,
   состояния и демонстрационного управления откройте «Подключение и мониторинг».

## Поддержанные редакторы

Перечисления: F01.01, F02.00, F02.12, F13.00, F15.00, F15.01, F15.05, F15.06.
Числа: F01.08, F03.00, F03.01, F13.01, F15.03, F15.04.
Остальные поля доступны для исследования, их типы не угадываются.

## Что сообщить по результату

Укажите версию, разрешение экрана, масштаб Windows (100/125/150/200 %),
действия и ожидаемый результат. Особое внимание: читаемость таблицы,
клавиатура, редакторы, сравнение и сохранность изменений после поиска.
Об ошибке можно сообщить: https://github.com/uzbatsu-beep/A650/issues

Это технический прототип. Совместимость с реальным ПЧ, импортом производителя
и полноценная Windows-приёмка ещё не подтверждены. Приложение не подписано.
Для деталей смотрите `RELEASE-NOTES-ru.md`.

## Экспериментальная диагностика стенда

В PowerShell из папки приложения выполните `./a650.exe diagnostics --help`.
Команда работает с физическим портом, автоматически из GUI не запускается.
Для подготовки стенда и примера запуска смотрите `BENCH-DIAGNOSTICS-ru.md`.
