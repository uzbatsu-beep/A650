# Примеры кадров Modbus RTU

Все примеры — ведомый `0x01`. Hex дан как последовательность байт transmission‑order (CRC младшим байтом вперёд).

## Подтверждено руководством (Приложение А.8) — использовать как golden‑тесты

### 1. Уставка частоты 30.00 Гц (запись 0x06 в 0x2001) — А.8.2
Запрос:
```text
01 06 20 01 0B B8 D4 88
```
Ответ (эхо):
```text
01 06 20 01 0B B8 D4 88
```
Разбор: адрес `0x01`, функция `0x06`, регистр `0x2001`, значение `0x0BB8` = 3000 → 30.00 Гц (масштаб 0.01), CRC `D4 88`.

### 2. Пуск вперёд (запись 0x06 в 0x2000 = 0x0001) — А.8.3
Запрос / ответ (эхо):
```text
01 06 20 00 00 01 43 CA
```

### 3. Останов с замедлением (запись 0x06 в 0x2000 = 0x0005) — А.8.4
Запрос / ответ (эхо):
```text
01 06 20 00 00 05 42 09
```

## Частично подтверждено — запрос валиден, ответ требует захвата с прибора

### 4. Чтение рабочей частоты U00.00 (0x03, регистр 0x3000)
Запрос (CRC верифицирован вручную = `8B 0A`; адрес согласуется с А.4.3):
```text
01 03 30 00 00 01 8B 0A
```
Ожидаемый ответ (формат 0x03; **значение и CRC НЕ подтверждены фрагментом руководства — захватить с прибора**):
```text
01 03 02 <hi> <lo> <crc_lo> <crc_hi>
```
Например при 50.00 Гц данные = `13 88` (0x1388 = 5000). Не зашивать конкретный hex ответа в golden‑тест до верификации.

## Гипотеза (unverified) — НЕ использовать как golden без проверки

### 5. Попытка записи в регистр только для чтения
Предполагаемый запрос (запись 0x06 в 0x3000):
```text
01 06 30 00 13 88 <crc>   # CRC и сам факт поведения — hypothesis
```
Предполагаемый exception‑ответ:
```text
01 86 <exc_code> <crc>     # exc_code и CRC — hypothesis
```
В присланном фрагменте этот обмен отсутствует. Код исключения для «read‑only» в руководстве не раскрыт. Проверить захватом; до проверки операция помечается experimental.

## 6. Пример расчёта CRC (для автотестов)
Вход (адрес+функция+данные): `01 03 30 00 00 01` → CRC‑16/MODBUS = `0x0A8B` → передача `8B 0A`. Совпадает с примером 4 — это опорный вектор для unit‑теста CRC.

## Правила добавления примера
- Указывать раздел руководства (А.8.x) или пометку `hypothesis`.
- Для 0x06 ответ = эхо (подтверждено). Для 0x03 ответ — только захваченный с прибора.
- Каждая фикстура дублируется в `data/frames/` с полями `verified_request`/`verified_response`.
