# ADR‑0001: использовать Modbus RTU как единственный транспорт

Статус: принято (черновик).  
Контекст: руководство A650 описывает RS‑485 Modbus RTU (Приложение А) как штатный канал конфигурирования.  
Решение: ПО строится поверх Modbus RTU; другие транспорты (если появятся) — отдельными ADR.  
Последствия: обязаны учитывать ограничения руководства (чтение ≤ 8 регистров, полином CRC 0xA001, конфликты формата/адреса) и держать read‑only по умолчанию.
