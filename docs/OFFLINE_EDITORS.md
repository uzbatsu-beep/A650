# Офлайн-редакторы параметров

Состояние на 15 ноября 2026. В каталоге используйте фильтр «Можно изменить
офлайн», затем дважды нажмите ячейку «Проект». Сохранение создаёт локальный
файл проекта `.a650.json`; этот формат не является `.ods` OniDriveStudio.
Редактирование и сравнение проектов не отправляют команды приводу и не
меняют настройки COM-порта. Пропущенный параметр означает «не задано».

Варианты сверены по предоставленному руководству A650, издание 3, таблица 5.2:

- F01.01 — источник частоты, стр. 44; F02.00 — источник команды, стр. 44;
  F02.12 — способ останова, стр. 45; F13.00 — задание ПИД, стр. 61;
- F15.00, F15.01 — скорость и формат, стр. 63; F15.05, F15.06 — режим
  ведущий/ведомый и источник данных, стр. 64. F15.01 дополнительно сверен
  с подробным описанием на стр. 133, поскольку сводная таблица противоречива.

Перечисления хранятся числовыми кодами, пользователь видит название.
Неизвестный код при загрузке проекта сохраняется и показывается как
«Неизвестное значение»; заново выбрать его нельзя. Только известные варианты
принимаются при локальном редактировании. Применимость к конкретной модели
и прошивке требуется проверить; метаданные не разрешают запись в ПЧ.

Числовые поля с точным Decimal и шагом: F01.08 20,00–600,00 Гц (0,01),
F03.00/F03.01 0,0–6000,0 с (0,1), F13.01 0,0–100,0 % (0,1), F15.03
0,0–60,0 с (0,1), F15.04 0–200 мс (1). Границы приведены по табл. 5.2
руководства: стр. 44–45, 61, 63–64. Для F13.01 также использовано насосное
руководство, стр. 19. Наличие офлайн-редактора не подтверждает масштаб
слова Modbus, зависимости от других параметров или разрешение физической записи.

Остальные параметры остаются для просмотра. Дубликаты и конфликты адресов не
становятся редактируемыми автоматически. Сравнение доступно между файлами
офлайн-проекта, без чтения привода; совместимость с реальным `.ods` и
корректность на устройстве пока не проверены.
