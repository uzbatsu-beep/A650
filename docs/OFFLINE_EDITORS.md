# Офлайн-редакторы параметров

Состояние на 15 ноября 2026. В каталоге используйте фильтр «Можно изменить
офлайн», затем дважды нажмите ячейку «Проект». Сохранение создаёт локальный
файл проекта `.a650.json`; этот формат не является `.ods` OniDriveStudio.
Редактирование и сравнение проектов не отправляют команды приводу и не
меняют настройки COM-порта. Пропущенный параметр означает «не задано».

Варианты сверены по предоставленному руководству A650, издание 3, таблица 5.2:

- F01.01 — источник частоты, стр. 44; F02.00 — источник команды, стр. 44;
  F02.12 — способ останова, стр. 45; F13.00 — задание ПИД, стр. 61;
- F15.00, F15.01 — скорость и формат, стр. 63; F15.05, F15.06 — режим
  ведущий/ведомый и источник данных, стр. 64. F15.01 дополнительно сверен
  с подробным описанием на стр. 133, поскольку сводная таблица противоречива.

Перечисления хранятся числовыми кодами, пользователь видит название.
Неизвестный код при загрузке проекта сохраняется и показывается как
«Неизвестное значение»; заново выбрать его нельзя. Только известные варианты
принимаются при локальном редактировании. Применимость к конкретной модели
и прошивке требуется проверить; метаданные не разрешают запись в ПЧ.

Числовые поля с точным Decimal и шагом: F01.08 20,00–600,00 Гц (0,01),
F03.00/F03.01 0,0–6000,0 с (0,1), F13.01 0,0–100,0 % (0,1), F15.03
0,0–60,0 с (0,1), F15.04 0–200 мс (1). Границы приведены по табл. 5.2
руководства: стр. 44–45, 61, 63–64. Для F13.01 также использовано насосное
руководство, стр. 19. Наличие офлайн-редактора не подтверждает масштаб
слова Modbus, зависимости от других параметров или разрешение физической записи.

Остальные параметры остаются для просмотра. Дубликаты и конфликты адресов не
становятся редактируемыми автоматически. Сравнение доступно между файлами
офлайн-проекта, без чтения привода; совместимость с реальным `.ods` и
корректность на устройстве пока не проверены.

## История и сравнение проектов

Изменения отменяются кнопкой «Отменить» (Ctrl+Z) и возвращаются кнопкой
«Повторить» (стандартное сочетание Redo). История независима для A650/A650M.
Отмена может вернуть отсутствие значения или неизвестный enum-код из файла,
не заменяя его допустимым вариантом. Сохранение отмечает текущее состояние:
возврат к нему снимает признак несохранённых изменений. Повторный ввод того
же значения не создаёт лишнего шага истории. После нового изменения ветка
повтора сбрасывается. История действует только в открытом сеансе.

«Сравнить с проектом» показывает именованное значение образца рядом со
значением проекта. Статусы различают совпадение, отличие, отсутствие в
проекте, отсутствие в образце и отсутствие в обоих. Фильтр «Только отличия»
учитывает параметры, которые присутствуют лишь с одной стороны. Отсутствие
ключа не считается нулём или заводским значением. «Закрыть сравнение» не
сбрасывает редактирование и историю. Сравнивать проекты разных моделей нельзя.
Данные реального ПЧ этим действием не считываются.

## Чтение симулятора в каталог

После подключения в режиме «Симулятор» кнопка «Считать из симулятора» читает
перечисления из текущего отфильтрованного списка. Запросы FC03 выполняются
последовательно в рабочем потоке; запись не выполняется. Демонстрационные
значения находятся в FakeTransport и не объявляются заводскими настройками
какой-либо прошивки. В колонке «ПЧ · симулятор» показаны именованное значение,
время последнего успешного чтения и статус актуальности. Через 5 секунд,
при отключении или ошибке чтения последнее значение отмечается устаревшим;
оно не заменяется нулём. После смены модели показания очищаются. Ответы
предыдущего сеанса не применяются к новому сеансу или модели.

Значения симулятора не изменяют проект и его историю. Для заданного проектного
значения показывается совпадение/отличие от актуального показания. Если масштаб
числового параметра не подтверждён, отображается отсутствие кодека. Чтение
этого раздела через физический serial-порт пока заблокировано. Это отдельная
функция от существующего прототипа мониторинга состояния привода.

## Перенос выбранных значений и очистка

Выберите строки в таблице (Ctrl/Shift для нескольких) и нажмите «Взять
выбранные из образца». Значения образца одной модели переносятся только
в офлайн-проект. Каждый выбранный параметр должен иметь поддержанный
редактор, допустимое значение в образце и не иметь конфликта/дубликата.
Если проверка хотя бы одной строки не проходит, весь набор остаётся без
изменений; причина доступна в подсказке недоступной кнопки. Сам обработчик
повторно проверяет условия, а не полагается на состояние кнопки.

«Убрать локальные значения» удаляет выбранные уставки из проекта. Это не
присваивание нуля, не загрузка заводских значений и не команда на ПЧ.
Перенос или очистка нескольких строк — один шаг undo/redo. Пустая операция
не создаёт историю. При фильтре отличий успешно выровненные строки исчезают
из списка; undo возвращает их. При множественном выборе справа показывается
сводка значений. Чтение и запись в привод этими действиями не выполняются.
