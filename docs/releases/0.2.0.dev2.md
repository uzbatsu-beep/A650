# ONI A650 · 0.2.0.dev2

Актуальный промежуточный Windows x64 релиз на основе `main` после PR #10,
#11 и #12 (базовый коммит `d908305`), с исправлениями подготовки релиза.

## Новое по сравнению с 0.2.0.dev1

- Управление проектом, модель, группы, фильтры, импорт и чтение перенесены
  в левую сворачиваемую панель. Кнопка «☰» возвращает скрытую панель.
- Поиск и число найденных параметров находятся над таблицей. Освобождено
  место по вертикали для параметров и сведений справа.
- Добавлена экспериментальная стендовая диагностика только для чтения.
  В этой сборке она доступна через `a650.exe diagnostics --help`, без Python.
  Инструкция включена в ZIP как `BENCH-DIAGNOSTICS-ru.md`.
- Перед выпуском из списка опроса исключены все три известных пароля:
  пользовательский, заводской и дилерский. Параметры с названием «пароль»
  также не опрашиваются.

Сохранены 14 типизированных офлайн-редакторов, проекты и сравнение, undo/redo,
чтение enum из симулятора, экспериментальный предпросмотр ODS и примеры.

## Запуск

Скачайте `a650-windows-x86_64-0.2.0.dev2.zip`, распакуйте целиком и запустите
`start-preview.cmd`. Откроется каталог с редактируемыми параметрами и симулятором.
Проверочный сценарий — в `README-ru.md` внутри архива.

Для диагностики физического стенда сначала прочитайте отдельную инструкцию:
она не запускается автоматически. Используется FC03 по одному raw-регистру,
без записей и повторов; ошибки сохраняются в новый JSONL-файл.

## Ограничения и проверка сборки

Это технический прототип, не завершённая промышленная альфа. Стендовая
приёмка и применимость к модели/прошивке ещё не подтверждены. Чтение каталога
в GUI остаётся доступным только через симулятор. Диагностика не интерпретирует
неизвестные масштабы и signedness и не разрешает запись параметров.

ODS восстановлен по EXE и проверяется на синтетических данных; перенос чисел
без подтверждённого масштаба заблокирован. Приложение не подписано.

Windows workflow выполняет тесты, сборку, проверку версии, `diagnostics --help`
и запуск GUI с симулятором. Ручная оценка интерфейса и DPI на Windows остаётся
необходимой. Точный релизный коммит и SHA-256 EXE — в `BUILD-INFO.json`;
контрольная сумма ZIP опубликована отдельным файлом `.sha256`.
