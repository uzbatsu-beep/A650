# ONI A650 · 0.2.0.dev1

Промежуточный релиз для оценки интерфейса и офлайн-сценариев на Windows x64.
Технический прототип; это ещё не завершённая альфа конфигуратора.
Основа — `main` после слияния PR #8; версия, стартовый экран и упаковка
обновлены отдельным релизным коммитом.

## Что изменилось с первого preview

- Приложение открывается на параметрах, доступных для офлайн-редактирования.
  Полный исследовательский каталог доступен после снятия фильтра.
- В таблице работают 8 именованных enum и 6 числовых редакторов с единицами,
  точным десятичным вводом, диапазоном и шагом. Подробнее — в README архива.
- Проекты `.a650.json`: сохранение, открытие, отдельные проекты A650/A650M,
  защита несохранённых изменений, undo/redo.
- Сравнение с проектом-образцом, фильтр отличий, перенос выбранных значений
  и удаление локальных уставок одним действием отмены.
- Ручное чтение enum из симулятора, время чтения, устаревание и сравнение
  с локальными значениями.
- Предпросмотр OniDriveStudio ODS: отдельные Set/Read/Check, текущее и будущее
  значение проекта, перенос явно выбранных известных enum, скрытие паролей.
- Раздельные версионируемые профили редакторов с источниками и проверкой схемы.
- Единая версия в CLI, пакете и заголовке окна; в архив включены инструкция,
  демонстрационные файлы и BUILD-INFO.json с SHA-256 исполняемого файла.

## Запуск и оценка

Скачайте `a650-windows-x86_64-0.2.0.dev1.zip`, распакуйте целиком и запустите
`start-preview.cmd`. Python и установка зависимостей не требуются.
Откроются каталог параметров и подключение к встроенному симулятору.
Пошаговый сценарий проверки находится в `README-ru.md` внутри архива.

## Ограничения

- Физическое чтение параметров каталога, их запись и применимость к конкретной
  модели/прошивке не подтверждены. Все новые операции меняют только проект.
- ODS восстановлен по EXE; настоящего файла экспорта пока нет.
  Масштаб чисел неизвестен, их перенос заблокирован. Пример в ZIP синтетический.
- Полный каталог из EXE содержит неподтверждённые поля, дубликаты и конфликты.
  Эти строки не становятся редактируемыми автоматически.
- Симулятор не воспроизводит двигатель, разгон и все отказы оборудования.
- Приложение не подписано. DPI, доступность и пользовательские сценарии
  требуют ручной проверки на Windows. Автотест запуска этого не заменяет.

Windows ZIP публикуется workflow только после тестов, сборки и проверки
запуска исполняемого файла. Точный коммит и контрольная сумма — в BUILD-INFO.json.
