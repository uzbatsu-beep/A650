# ONI A650 0.2.0.dev3 — диагностика чтения регистров (предварительная версия)

Эта предварительная сборка предназначена **только для стендовой проверки** реального
ПЧ A650/A650M и совместима с Windows 10 x64. До отдельной приёмки на реальном
оборудовании не использовать для управления технологическим процессом.

## Что изменилось
- Устранён обязательный FC03 Count=4 на 0x2100–0x2103: состояние, биты,
  аварию и предупреждение приложение читает по одному регистру.
- Чтение частоты 0x3000 и остальных показаний не зависит от ошибки
  отдельного регистра.
- Добавлен безопасный сканер известных адресов F/U-каталога:
  FC03 Count=1, ограниченный список, отсутствие записи.
- В интерфейсе: старт/остановка диагностики, прогресс и продолжение из JSONL.
- Результат: JSONL + CSV, время, качество, сырое значение, запрос и ошибки.
- Исключены пароль F00.00, EEPROM, H-группы, команда 0x2000 и 0x2005.

## Запуск
Распакуйте ZIP целиком и запустите `start-preview.cmd`. Выберите модель
и параметры интерфейса RS-485, подключитесь **без разрешения записи**,
на вкладке «Подключение и мониторинг» нажмите «Сканировать каталог…».
Инструкция: `docs/BENCH_DIAGNOSTICS.md` в GitHub.

## Ограничения
- Реальные RX-байты пока не сохраняются; `request_hex` — расчётный TX.
- Успешное чтение ещё не подтверждает масштаб или корректность интерпретации.
- Работа с реальным ПЧ, Windows GUI и USB–RS-485 должна быть отдельно проверена.
- Нельзя считать экспериментальную карту универсальной для всех прошивок.
- Запись параметров, пуск и останов не входят в процедуру сканирования.

Сборка PR для предварительной проверки **не является опубликованным релизом**.
