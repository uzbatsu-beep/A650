# Фактическое состояние разработки

Срез на 15 ноября 2026 года: ветка `codex/a650-interface-preview`, включая
чтение симулятора и перенос/очистку выбранных уставок в офлайн-проекте.

**Степень готовности: технический прототип с интерактивным офлайн-редактором.**
Это ещё не завершённая альфа промышленного конфигуратора. Нет подтверждения
полноценного параметрирования реального ПЧ. Рабочая цель и порядок следующих
этапов зафиксированы в [плане](DEVELOPMENT_PLAN.md), целевое поведение экранов —
в [дизайне интерфейса](INTERFACE_DESIGN.md).

## Реализовано

| Область | Фактический результат | Ограничения |
|---|---|---|
| Протокол | CRC, запросы FC03/FC06, проверка функции/длины/числа значений и эха; чтение до 8 регистров | Полный RTU timing, поздние ответы и физические помехи требуют доработки/стенда |
| Повторы | Чтение может повторяться, запись при тайм-ауте не повторяется; отдельная ошибка неизвестного исхода | Политика неизвестного исхода ещё не завершена для всех ошибок после отправки |
| Подключение | Русская форма: порт, обновление списка, скорость, N/E/O, стоповые биты, адрес, тайм-аут, повторы; пробное чтение | Ответ не идентифицирует автоматически модель/прошивку |
| Симулятор | Пуск вперёд, уставка, останов, состояние и демонстрационные значения перечислений | Нет модели двигателя, реального разгона, полного поведения аварий и всех команд |
| Каталог | A650/A650M раздельно, поиск и группы, источники и конфликты, поставка данных внутри пакета | Выгрузки EXE — исследовательские данные; не полный проверенный профиль |
| Метаданные | Арифметика F/U адресов, аудит дубликатов и расхождений | H00, некоторые масштабы, доступы и знаковость не подтверждены для всего каталога |
| Редакторы | 8 enum и 6 числовых параметров; enum — именованный список, числа — Decimal с диапазоном/шагом | Только офлайн. Остальные поля заблокированы; типы не угадываются из непрозрачных полей EXE |
| Неизвестные enum | Сохранение/открытие неизвестного кода без подмены первым вариантом | Вновь выбрать недопустимое значение нельзя; это не подтверждает физический кодек |
| Проект | Версионируемый `.a650.json`, атомарное сохранение, открытие, защита несохранённых изменений | Не является форматом OniDriveStudio `.ods`; пользовательские значения ограничены поддержанными редакторами |
| История | Undo/redo отдельно для каждой модели, корректная точка сохранения, отсутствие ложного изменения при повторном вводе | История хранится только в текущем сеансе |
| Сравнение | Два офлайн-проекта одной модели, именованные значения, отдельные статусы отсутствия, фильтр отличий | Есть перенос выбранных значений образца в проект; экспорта отчёта нет |
| Чтение в каталог | Кнопка чтения поддержанных enum через очередь контроллера и Modbus-симулятор, сравнение с проектом | Физический serial для этой функции заблокирован; числовые поля без codec не считываются как инженерные |
| Качество показаний | Последнее время успешного чтения, stale через 5 с / при отключении / ошибке; отбрасывание старого ответа по токену | Реализовано для показаний каталога, не для всех старых виджетов мониторинга |
| ODS | Офлайн-парсер INI-структуры по анализу EXE, проверки модели и неоднозначного ввода | Нет GUI-импорта, настоящего образца ODS и проверки обратного экспорта |
| Сборки | PyInstaller, workflow Windows preview, tag-triggered prerelease, запуск симулятора через CMD | Успех последнего запуска Actions и опубликованный asset агентом не подтверждены |

### Поддержанные поля офлайн-проекта

Enum: **F01.01, F02.00, F02.12, F13.00, F15.00, F15.01, F15.05, F15.06**.

Числовые: **F01.08, F03.00, F03.01, F13.01, F15.03, F15.04**.

Диапазоны, источник и инструкции — [OFFLINE_EDITORS.md](OFFLINE_EDITORS.md).
Выбор значения не меняет параметры соединения и не отправляет запись в ПЧ.

## Исследования и результаты

- Предоставленный `ONI_A650M_Manual.pdf` имеет титул A650, издание 3.
  Имя файла не доказывает применимость к конкретному A650M/прошивке.
- Из EXE (внутренняя версия 1.2.7.0) извлечены 531 запись A650 и 617 A650M;
  это 530/616 уникальных кодов из-за дублирования F17.28.
- Подтверждены ошибочные примеры F13/F15 адресации в ранних заметках,
  дубликат F17.28 и 10 сдвигов F18 в извлечённом профиле A650M.
- Архив A650.zip исследован: 3 DOCX, 4 MD, HTML-макет, XLSX. В нём нет
  реального ODS. Полнота заявленного справочника не доказана; ошибки команд,
  адресов, PID-групп и пределов пакетного чтения зафиксированы.
- Доступные Qt/W3C материалы использованы в дизайне; независимый бенчмарк
  ABB/Schneider/Danfoss пока не завершён из-за недоступности сайтов.

Подробные свидетельства и ограничения: [UPLOADED_MATERIALS.md](UPLOADED_MATERIALS.md),
[ARCHIVE_REVIEW.md](ARCHIVE_REVIEW.md), [ODS_FORMAT.md](ODS_FORMAT.md).

## Проверки и их практические пределы

Последний завершённый прогон: **177 тестов прошли** на Linux / Python 3.12 /
Qt offscreen. Включены проверки протокола, симулятора, GUI-редакторов,
проектов, истории, сравнения, чтения каталога и обработки устаревания.
Проверена загрузка каталога из собранного Python wheel и запуск Linux-бинарника
на предыдущем этапе; это не проверка бинарника Windows текущего коммита.

Пользователь показывал скриншоты Windows-прототипа. Это подтверждает запуск
одной предыдущей версии, но не весь сценарий и не Windows-приёмку текущей
ветки. USB–RS-485, модель/прошивка и реальные чтение/запись ПЧ не проверены.
После переноса метаданных редакторов в профили выполнен полный прогон тестов.

## Не завершено и не должно объявляться готовым

- Полноценная GUI-альфа по критериям дизайна: покрытие метаданных,
  валидация зависимостей, полноценный проект и Windows-приёмка.
- Физическое чтение каталога и применение проектных параметров на ПЧ.
- Раздельные разрешения параметризации и движения во всех CLI/GUI-путях,
  предварительный аудит и полный учёт ошибок/неизвестного исхода.
- Корректная отрицательная частота во всех виджетах, общая политика stale,
  ограничение фоновой очереди, полный набор отказов и таймингов RTU.
- Типизированные bitfield/десятичные разряды, зависимости диапазонов,
  редакторы всех параметров, мастера/Scope/отчёты/мультиприводные проекты.
- Реальная совместимость импорта/экспорта ODS.

Последнее дополнение: пакетный перенос из образца и удаление локальных уставок
с полной предварительной проверкой и единым шагом undo/redo.

Добавлены отдельные версионируемые JSON-профили редакторов A650/A650M:
валидация, provenance, неизменяемые метаданные и фиксация ревизии в проекте.
Профили проверены в собранном wheel; аппаратные codec и разрешения записи
не добавлены. См. [EDITOR_PROFILES.md](EDITOR_PROFILES.md).

Запуск разработки: установить `.[dev,build]`, выполнить
`QT_QPA_PLATFORM=offscreen python -m pytest tests/ -q`.
Ручная оценка: `a650 --simulate gui` → «Каталог параметров» → фильтр
«Можно изменить офлайн». Windows preview: распаковать артефакт и запустить
`start-preview.cmd`. Среда, коммит Git, удалённая ветка, merge в main и GitHub
Release — разные результаты; фиксировать только фактически выполненные.
